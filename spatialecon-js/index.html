Agent-based modelling and spatial economics

The models from Dan Olner's 2013 PhD, running live in the browser. Each one is the thesis' own experiment, rebuilt from the original Java and re-verified against the published figures.

Every model page has notes on what to watch, the economics behind it, how it is actually built — and, where there is one, what the rebuild found that the thesis did not say. Those disagreements are the point rather than an embarrassment: one figure turned out to be plotting a different variable than its label claims, and one result still has not reproduced.

If you want the argument before the models, start with how these models are built — and what that costs: why an agent's budget is a day rather than money, which kind of decision quietly breaks, and why showing something is the start of an explanation rather than the end.

Forty-two models from the thesis — the whole catalogue, all seven groups — and a curiosity from the years of building it. Several are not agent models at all — two are closed forms you could do on paper, one is a difference equation, and one is Krugman's Core Model, which is what everything else is measured against.

No dependencies, no build step, nothing to install. The stills are rendered by the same view code the live models use.
